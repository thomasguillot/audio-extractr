# Agent Guide — Audio Extractr

This file is the authoritative agent/AI guide for this repo. CLAUDE.md imports it via `@AGENTS.md`.

## What this project is

A native macOS app that turns video into MP3, from a link or a local file: paste a URL
or drop a media file, optionally trim and adjust speed, save as MP3, with an optional
on-device transcript. Bundles yt-dlp + ffmpeg (separate child processes, never linked).
Targets macOS 26 (Tahoe)+, Apple Silicon only. Unsigned — no Apple Developer Program,
no signing, no notarization, ever. MIT.

## Repo layout

```
audio-extractr/
├── ExtractrKit/       # Pure Swift package (Swift 6, Swift Testing). All logic lives here.
├── App/               # SwiftUI macOS app. Thin UI over ExtractrKit.
│   ├── Sources/
│   ├── project.yml    # XcodeGen source of truth — edit this, not the .xcodeproj
│   └── AudioExtractr.xcodeproj  # generated by xcodegen; git-ignored
├── Support/binaries/  # yt-dlp + ffmpeg, fetched by scripts/fetch-binaries.sh (git-ignored)
├── scripts/           # fetch-binaries.sh, make-icon.sh, make-dmg.sh
└── site/              # marketing site, deployed to GitHub Pages by Actions
```

`docs/` is git-ignored. Specs and plans are written there for reference and stay untracked.

## Build and test

```sh
cd ExtractrKit && swift test          # all logic tests, no Xcode needed
./scripts/fetch-binaries.sh           # once, before first app build
cd App && xcodegen                    # after any project.yml / file add/remove
cd App && xcodebuild -project AudioExtractr.xcodeproj -scheme AudioExtractr \
  -destination 'platform=macOS' build
cd <repo root> && swiftlint lint --quiet   # NEVER run swiftlint from App/
```

SourceKit diagnostics right after xcodegen (No such module 'ExtractrKit', etc.) are
always false — trust `swift test` and `xcodebuild`.

## Coding conventions

- Swift 6, strict concurrency. `@MainActor` on `AppModel`. `@Observable`, not `ObservableObject`.
- Swift Testing, not XCTest. TDD: ExtractrKit changes start with a failing test.
- Comments to a strict minimum — only invariants invisible from the code, one terse line.
- YAGNI. No abstraction beyond what the current task requires.

## Security invariants — do not break these

- **URL acceptance:** `URLPolicy.validated(_:)` is the single enforcement point —
  https-only, loopback/private hosts rejected. Every path that accepts a remote URL
  must go through it.
- **Process boundary:** only `ProcessRunner` spawns child processes. Arguments are
  passed as arrays — never through a shell. Exception: `UpdateInstaller` (ported
  verbatim from Hosts Switchr) runs hdiutil/ditto/xattr via its own argument-array
  helper and a detached `/bin/sh` relauncher; its `appPath` must remain a
  compile-time constant — do not interpolate variables into that script.
- **yt-dlp updates:** `YtDlpUpdater` verifies the downloaded binary against the
  release's `SHA2-256SUMS` before an atomic replace; a failed verify leaves the
  previous binary untouched.
- **ffmpeg is bundled-only** — never executed from a user-writable location.

## Known limitations

- `URLPolicy` blocks literal private/loopback IPs, not hostnames that resolve to
  them (DNS rebinding is out of scope).
- Local-file probing parses `ffmpeg -i` stderr (no ffprobe bundled — an
  intentional spec deviation).
- Acknowledgements ship in the DMG and repo, not the About panel.

## Commit conventions

Conventional commit prefixes (`feat:`, `fix:`, `chore:`, `refactor:`, `test:`, `docs:`).
No `Co-Authored-By` trailers. `main` is protected once on GitHub — branch, push, PR,
squash/rebase merge.

## Releasing

Bump `MARKETING_VERSION` in `App/project.yml` → `./scripts/make-dmg.sh` →
`gh release create vX.Y.Z dist/AudioExtractr-X.Y.Z.dmg --title "Audio Extractr X.Y.Z" --notes "…" --latest`
with the unsigned first-launch note and the DMG SHA-256 in the body.

## What NOT to do

- Do not add signing, notarization, or sandboxing.
- Do not commit `Support/binaries/`, `dist/`, or anything under `docs/`.
- Do not run SwiftLint from `App/`.
- Do not add `Co-Authored-By` to commits.
